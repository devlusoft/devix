# Security

## Reporting a vulnerability

Please report security issues via GitHub Security Advisories:
https://github.com/devlusoft/devix/security/advisories/new

Do NOT open a public issue for security vulnerabilities.

## Response

devlusoft maintains devix. We acknowledge reports within 3 business days
and aim to ship a fix within 30 days for high-severity issues.

## Scope

This policy covers devix itself: `packages/devix/`. For vulnerabilities
in upstream dependencies (Solid, Vite, @solidjs/router), report to
the upstream project.

## Versions

Security fixes are backported to the current branch and the previous
major version. Older branches are not maintained.
